# 📊 Sales Insights Dashboard

## 📌 Project Overview
This project explores **sales, profit, and quantity metrics** across multiple states and time periods to provide deep insights into regional and yearly performance.  
The dashboard helps businesses **track growth, identify trends, and drill down into regional performance**.

---

## 📊 Key Objectives
1. Track **Sales, Profit, and Quantity** with dynamic measure selection.  
2. Compare **Current Year vs Previous Year (YoY)** to identify growth trends.  
3. Visualize **monthly performance trends** using sparklines and average reference lines.  
4. Analyze **state-wise sales performance** using bubble maps and bar charts.  
5. Enable **interactive exploration** via KPI tables and filters.  

---

## 🗂️ Data Sources
- **Sales Transactions Data** – including sales, profit, and quantity  
- **Geographical Data** – state-level mapping for regional insights  

---

## ⚙️ Tech Stack
- **Power BI Desktop** – Data cleaning, modeling, visualization  
- **DAX** – Custom measures for YoY growth, dynamic metric selection  
- **Excel/CSV** – Raw data source files  

---

## 📈 Dashboard Highlights
- 📍 **Regional Sales Map**: Bubble maps showing sales intensity by state  
- 📉 **Year-over-Year Comparisons**: Growth trends across KPIs  
- 📊 **Monthly Trends**: Sparklines with average lines for quick insights  
- 🗂️ **Interactive KPI Table**: Drill down into granular sales data  

---

## 🚀 How to Use
1. Clone/download this repository.  
2. Open the `.pbix` file in **Power BI Desktop**.  
3. Use slicers (Year, Metric, State) to filter and explore insights.
