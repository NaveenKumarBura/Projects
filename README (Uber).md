# 🚖 Uber Rides Data Analytics Dashboard

## 📌 Project Overview
This project analyzes **Uber ride data** to uncover patterns in ride demand, customer behavior, and revenue trends.  
The dashboard provides **time-based, location-based, and category-based insights** to help optimize operations and improve decision-making.

---

## 📊 Key Objectives
1. Analyze **total rides, revenue, and average fare** across different time periods.  
2. Explore **peak ride hours** and **day-of-week patterns** for demand forecasting.  
3. Compare **ride types (UberX, UberXL, etc.)** for popularity and revenue contribution.  
4. Identify **city/region-wise demand hotspots**.  
5. Enable **interactive exploration** with filters for time, location, and category.  

---

## 🗂️ Data Sources
- **Uber Rides Dataset (CSV)** – includes date/time, city, ride type, fare, and customer details  
- **Location Data** – city/region information for geographical insights  

---

## ⚙️ Tech Stack
- **Power BI Desktop** – Data transformation, modeling, and dashboard development  
- **DAX** – Custom measures (average fare per ride, peak hours, YoY growth)  
- **Excel/CSV** – Raw dataset storage  

---

## 📈 Dashboard Highlights
- ⏰ **Time Analysis**: Rides by hour, day, and month with peak demand identification  
- 🏙️ **Location Insights**: Heatmap of rides by city/region  
- 🚖 **Ride Category Performance**: Revenue and ride count split by ride type  
- 📊 **Trend Analysis**: Monthly revenue and ride growth trends  
- 💰 **Average Fare Insights**: Distribution of fare per ride and category  

---

## 🚀 How to Use
1. Clone/download this repository.  
2. Open the `.pbix` file in **Power BI Desktop**.  
3. Use slicers (Date, City, Ride Type) to interact with the dashboard.
